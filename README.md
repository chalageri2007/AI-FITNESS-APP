# AI-FITNESS-APP
AI Fitness Assistant is a smart web application that helps users achieve their health and fitness goals through personalized recommendations. It calculates Body Mass Index (BMI), tracks fitness progress, and provides customized workout and nutrition suggestions.
 🏋️ Fitness AI Studio

*Fitness AI Studio* is a modern AI-powered fitness and health analytics web application built using *Python, **Streamlit, **Google Gemini AI, **Pandas, and **Plotly*. It helps users monitor their health, calculate fitness metrics, generate personalized diet and workout plans, receive AI-powered coaching, and track their progress through interactive dashboards.

---

## 📌 Project Overview

Fitness AI Studio combines health analytics with Artificial Intelligence to provide personalized fitness guidance. The application features an attractive dark-themed interface and offers multiple health tools in one platform.

---

## ✨ Features

### 📊 BMI Analytics
- Calculate Body Mass Index (BMI)
- Classifies weight status:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Instant health recommendations

---

### 🔥 Daily Calorie Calculator
- Calculates daily calorie requirement
- Maintenance Calories
- Fat Loss Calories
- Muscle Gain Calories
- Activity-based calorie estimation

---

### 💧 Hydration Tracker
- Calculates daily water intake
- Workout-based hydration recommendation
- Water intake displayed in liters
- Glass equivalent calculation

---

### 🥗 AI Diet & Workout Plan Generator
Generate personalized plans based on:
- Weight Goal
- Experience Level
- Fitness Goal

Supports:
- Weight Loss
- Muscle Gain
- Maintenance

AI generates:

- Lunch
- Snacks
- Dinner
- Workout Suggestions

### 🤖 AI Fitness Coach
Powered by *Google Gemini AI*

### 📈 Weight Progress Tracker
